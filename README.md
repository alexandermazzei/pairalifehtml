# PairaLife Website

This is a static HTML website for PairaLife, a platform connecting homeowners with people looking for housing.

## Structure

The website consists of the following main sections:

- **Main Pages**: Located in the root directory
- **About Pages**: Located in the `/about` directory
- **How It Works Pages**: Located in the `/how-it-works` directory

## Features

- Responsive design
- Consistent navigation across all pages
- Clear user flow for both homeowners and potential tenants
- Simple and clean styling

## Quick Start

To view the website locally, open `index.html` in your browser.

## Deployment

This site is designed to be deployed to GitHub Pages. Follow these steps:

1. Create a GitHub repository
2. Push all the files to the repository
3. Go to the repository settings
4. Scroll down to the GitHub Pages section
5. Select the branch you want to deploy (usually `main`)
6. Click Save

The site will be available at `https://[username].github.io/[repository]`.

## File Organization

- `index.html`: Main landing page
- `styles.css`: Global stylesheet
- `/about/`: About section pages
- `/how-it-works/`: How It Works section pages
- `/assets/`: Images and other static assets
