# PairaLife HTML Templates

This repository contains HTML templates for the PairaLife platform - a home-sharing service that matches homeowners with extra space to people seeking affordable housing through compatible living arrangements.

## Live Preview

These templates are available for preview via GitHub Pages at:
https://alexandermazzei.github.io/pairalifehtml/

## About This Project

This is a collection of static HTML templates for the PairaLife platform. These templates showcase the UI design and user flow for the platform.
